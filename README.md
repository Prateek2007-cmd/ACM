# ACM Student Chapter — Vasavi College of Engineering

Official repository for the ACM Student Chapter website at Vasavi College of Engineering (VCE), Hyderabad.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations & 3D:** GSAP, Lenis, Three.js / React Three Fiber

## Getting Started

### Installation

```bash
bun install
# or
npm install
```

### Development Server

```bash
bun run dev
# or
npm run dev
```

### Build

```bash
bun run build
# or
npm run build
```
